# Midnight Galaxy Theme

A dramatic and cosmic palette with deep, rich tones.

## Color Palette

| Role | Color | Hex Code |
|------|-------|----------|
| Primary | Deep Purple | `#553c9a` |
| Secondary | Nebula Blue | `#2b6cb0` |
| Accent | Stardust | `#faf089` |
| Background | Void Black | `#171923` |
| Text | Starlight | `#e2e8f0` |
| Muted Text | Cosmic Gray | `#718096` |

## Font Pairing

- **Headers**: Orbitron (sans-serif) - space-age and futuristic
- **Body**: Exo 2 (sans-serif) - modern and legible

## Usage

Best suited for:
- Space/astronomy content
- Gaming presentations
- Night events
- Entertainment brands

The deep cosmic palette creates mystery, wonder, and dramatic impact.
