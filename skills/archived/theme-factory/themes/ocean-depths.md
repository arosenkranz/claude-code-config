# Ocean Depths Theme

A professional and calming maritime theme inspired by deep ocean waters.

## Color Palette

| Role | Color | Hex Code |
|------|-------|----------|
| Primary | Deep Navy | `#1a365d` |
| Secondary | Ocean Teal | `#2c7a7b` |
| Accent | Seafoam | `#81e6d9` |
| Background | Soft Pearl | `#f7fafc` |
| Text | Deep Sea | `#1a202c` |
| Muted Text | Storm Gray | `#718096` |

## Font Pairing

- **Headers**: Playfair Display (serif) - elegant and professional
- **Body**: Source Sans Pro (sans-serif) - clean and readable

## Usage

Best suited for:
- Corporate presentations
- Financial reports
- Professional portfolios
- Business proposals

The deep blues convey trust and stability while the teal accents add visual interest without overwhelming.
