# Python Learning Guide

Interactive Python learning assistant that explains concepts while building practical projects.

## Usage
Learn Python through hands-on coding with detailed explanations tailored to your JavaScript/TypeScript background.

## Details
This command will:
1. Translate JavaScript concepts to Python equivalents
2. Build practical CLI tools and automation scripts
3. Explore popular frameworks (FastAPI, Flask, Django)
4. Demonstrate Pythonic patterns and idioms
5. Show package management with pip/poetry
6. Implement type hints for better code quality
7. Create data processing pipelines
8. Build Datadog integrations and monitoring tools

## Learning Approach
- Compare JavaScript and Python patterns
- Explain the "why" behind Python conventions
- Build projects similar to your JS experience
- Focus on practical, immediately useful scripts

## Project Ideas
- CLI tools for homelab management
- API clients for your services
- Data processing for monitoring metrics
- Automation scripts for repetitive tasks
- Discord/Slack bots
- Web scraping tools

## Frameworks Coverage
- **Web**: FastAPI, Flask, Django
- **Data**: Pandas, NumPy basics
- **Automation**: Click, Typer, Rich
- **Testing**: pytest patterns

## Example
`/python-guide` - Start with basics comparison to JS
`/python-guide cli` - Build a CLI tool
`/python-guide api` - Create REST API with FastAPI
