# Astro API Setup

Set up a modern Astro project with API functions, perfect for your personal website/blog rebuild.

## Usage
Create or enhance an Astro project with API endpoints, markdown content management, and modern JavaScript practices.

## Details
This command will:
1. Initialize an Astro project with TypeScript
2. Set up API routes with proper error handling
3. Configure local markdown content collections
4. Implement ESLint and Prettier configurations
5. Add Vite optimizations
6. Set up basic authentication if needed
7. Create deployment configurations for self-hosting
8. Integrate with your preferred frameworks (React components, Three.js for creative coding)

## Learning Focus
- Explains each configuration choice
- Shows how Astro's content collections work
- Demonstrates API function patterns
- Provides resources for further learning

## Example
`/astro-api-setup` - Create new Astro project with API
`/astro-api-setup blog` - Set up blog with markdown support
`/astro-api-setup creative` - Include P5.js/Three.js setup
