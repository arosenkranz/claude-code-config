# Pass 3: Content & Flow

Read the lesson start to finish as a learner would, without skimming. This is the holistic, narrative-level pass. Issues only visible when reading in sequence appear here. Do not scan; read.

---

## Lesson Opening

* **Expectation setting.** Does the intro tell the learner what they will accomplish in this lesson?
* **Scope clarity.** Is it clear what is and isn't covered?
* **Learning objective alignment.** Does the intro connect to the stated learning objectives?
* Flag openings that dive into content without first orienting the learner.

## Logical Flow

* **Natural topic progression.** Do topics build on each other in a sensible order?
* **Smooth transitions.** Are there clear connections between sections? Flag abrupt topic shifts with no transition sentence or phrase.
* **New information builds on prior knowledge.** Flag sections that introduce a new concept before the necessary prerequisite concept is covered.

## Progressive Disclosure

* **Introduce concepts near where they're needed.** Flag lessons that front-load all concepts before the learner needs them.
* **Don't over-explain upfront.** Details that only matter in step 5 shouldn't appear in the introduction.
* **Just-in-time context.** Background and context should appear immediately before the step that requires it, not several steps earlier.

## Step Gap Detection (Labs)

Read each step as if performing it yourself in the lab environment. Flag:

* **Skipped assumed knowledge.** A step references something the learner hasn't been taught yet (e.g., "Open the config file" without specifying which file or where it is).
* **Unclear target.** "Click here", "select it", "choose the option" — what is "here", "it", or "the option"? Flag vague references and identify what they should name specifically.
* **Missing context switch.** Moving between the lab environment and Datadog without signaling the switch. The learner should always know where they're supposed to be looking or acting.
* **Unexplained prerequisites.** A step references a resource, value, or state (e.g., a variable, an environment name, a file path) that hasn't been created or defined in any prior step.
* **Navigation without detail on first use.** The first time a learner navigates to a product area, instructions must include the full navigation path. Flag abbreviated instructions that appear before the first full navigation has been given.

## Conceptual Coherence

* **One idea per section.** Does each section under a heading stick to the topic stated in that heading?
* **Headings accurately describe their content.** Flag headings that are misleading or don't match what follows.
* **Consistent concept framing.** If a concept is described one way early in the lesson and described differently later, flag the inconsistency.

## Pacing

* **Walls of text.** Flag blocks of 3+ consecutive prose paragraphs that could benefit from headings, lists, or visuals to aid scannability.
* **Under-explained sections.** Flag steps or concepts that feel rushed or skipped relative to their complexity.
* **Over-explained sections.** Flag content that goes deeper than the target audience needs. (Particularly relevant for introductory-level courses.)

## Lesson Closing

* **Summary present.** Does the lesson close with a summary of what was covered?
* **Connection to learning objectives.** Does the closing connect back to what the learner was supposed to accomplish?
* **Forward reference.** Does the learner know what comes next (if applicable)?
* Flag lessons that end abruptly without a closing section.

## Cross-Lesson Consistency (when reviewing multiple lessons)

* **Consistent terminology.** Does terminology stay consistent across lessons? Flag if a concept is called one thing in lesson 2 and something different in lesson 4.
* **Correct back-references.** Do later lessons correctly reference concepts introduced in earlier ones? Flag references to "earlier" content that was either not covered or described differently.
* **Escalating complexity.** Does difficulty increase appropriately across the course? Flag if a later lesson introduces easier content than an earlier one.
