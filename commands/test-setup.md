# Test Setup & Strategy

Create comprehensive testing strategies with explanations to help you learn testing best practices.

## Usage
Set up testing frameworks and write tests for JavaScript/TypeScript and Python projects.

## Details
This command will:
1. Analyze your project to recommend appropriate testing frameworks
2. Set up test configuration files
3. Create example test suites with detailed comments
4. Implement different testing patterns (unit, integration, e2e)
5. Configure test coverage reporting
6. Set up CI/CD test pipelines
7. Provide testing best practices and patterns

## Framework Support
- **JavaScript/TypeScript**: Vitest, Jest, Playwright, Cypress
- **Python**: pytest, unittest, playwright
- **API Testing**: Supertest, pytest-httpx
- **Component Testing**: React Testing Library

## Teaching Approach
- Explains why each test is important
- Shows different testing patterns
- Demonstrates TDD/BDD approaches
- Provides resources for deeper learning

## Example
`/test-setup` - Analyze and set up testing
`/test-setup vitest` - Set up Vitest for Vite project
`/test-setup api` - Focus on API testing
