# Modern Minimalist Theme

A clean and contemporary grayscale theme with purposeful simplicity.

## Color Palette

| Role | Color | Hex Code |
|------|-------|----------|
| Primary | Charcoal | `#2d3748` |
| Secondary | Slate | `#4a5568` |
| Accent | Electric Blue | `#3182ce` |
| Background | Pure White | `#ffffff` |
| Text | Near Black | `#1a202c` |
| Muted Text | Gray | `#a0aec0` |

## Font Pairing

- **Headers**: Inter (sans-serif) - geometric and precise
- **Body**: Inter (sans-serif) - consistent and clean

## Usage

Best suited for:
- Tech presentations
- Data dashboards
- Modern portfolios
- Startup pitch decks

The minimal palette puts focus on content while the blue accent draws attention to key elements.
