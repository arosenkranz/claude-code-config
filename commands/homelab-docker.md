# Homelab Docker Optimization

Optimize Docker Compose stacks for your homelab environment with best practices for Raspberry Pi and resource constraints.

## Usage
Use this command to optimize Docker configurations for your homelab services.

## Details
This command will:
1. Analyze existing Docker Compose files
2. Optimize for ARM64 (Raspberry Pi 5) architecture
3. Configure resource limits for constrained environments
4. Set up proper networking between services
5. Implement health checks and restart policies
6. Configure volume mounts for Synology NAS integration
7. Add Datadog monitoring integration
8. Provide security hardening recommendations

## Considerations
- Optimizes for low-resource environments
- Ensures compatibility with Portainer
- Integrates with existing Home Assistant and Music Assistant
- Provides explanations for each optimization to help you learn

## Example
`/homelab-docker` - Analyze and optimize current Docker setup
`/homelab-docker plex` - Optimize Plex container for NAS deployment
