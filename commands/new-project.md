# Create New Web Project

I'll help you set up a new web project. First, let me gather some information:

## Project Details Needed:
1. **Project name**: What would you like to call this project?
2. **Project type**: What kind of project is this?
   - Static site (Astro, Vite)
   - React app (Vite, Next.js)
   - Full-stack app (Express + React, etc.)
   - CLI tool
   - Other?
3. **Features needed**:
   - TypeScript?
   - Testing framework?
   - Linting/Formatting (ESLint + Prettier)?
   - Git repository?
   - Docker setup?
4. **Any specific libraries or tools** you know you'll need?

Once you provide these details, I'll:
- Create the project structure in `~/Code`
- Set up the development environment
- Configure linting and formatting
- Initialize git repository
- Create initial README
- Set up any additional tools requested

I'll guide you through each step and explain what I'm doing so you can learn and modify the setup in the future.
