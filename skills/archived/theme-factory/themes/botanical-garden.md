# Botanical Garden Theme

A fresh and organic palette inspired by flourishing gardens.

## Color Palette

| Role | Color | Hex Code |
|------|-------|----------|
| Primary | Leaf Green | `#38a169` |
| Secondary | Petal Pink | `#ed64a6` |
| Accent | Sunshine | `#f6e05e` |
| Background | Soft Cream | `#fffff0` |
| Text | Garden Soil | `#2d3748` |
| Muted Text | Herb Gray | `#718096` |

## Font Pairing

- **Headers**: Quicksand (sans-serif) - friendly and organic
- **Body**: Poppins (sans-serif) - modern and approachable

## Usage

Best suited for:
- Garden and plant brands
- Organic products
- Spring events
- Wellness content

The fresh greens and floral accents create vitality and natural beauty.
