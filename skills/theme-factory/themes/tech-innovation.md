# Tech Innovation Theme

A bold and modern aesthetic for technology and innovation.

## Color Palette

| Role | Color | Hex Code |
|------|-------|----------|
| Primary | Electric Purple | `#805ad5` |
| Secondary | Cyber Blue | `#4299e1` |
| Accent | Neon Green | `#48bb78` |
| Background | Dark Slate | `#1a202c` |
| Text | Pure White | `#ffffff` |
| Muted Text | Cool Gray | `#a0aec0` |

## Font Pairing

- **Headers**: Space Grotesk (sans-serif) - futuristic and bold
- **Body**: IBM Plex Sans (sans-serif) - technical and readable

## Usage

Best suited for:
- Tech startups
- Product launches
- Developer conferences
- Innovation showcases

The dark background with vibrant accents creates a cutting-edge, futuristic feel.
