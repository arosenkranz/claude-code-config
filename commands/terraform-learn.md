# Terraform Learning Lab

Learn Infrastructure as Code with Terraform through practical, guided examples tailored to your learning style.

## Usage
Create Terraform configurations with detailed explanations, starting from basics to advanced patterns.

## Details
This command will:
1. Create beginner-friendly Terraform configurations
2. Explain each resource and argument
3. Show best practices for structure and organization
4. Demonstrate state management
5. Implement modules for reusability
6. Set up remote backends (S3)
7. Create practical examples for AWS services
8. Show cost optimization techniques

## Learning Path
- **Beginner**: Basic resources, variables, outputs
- **Intermediate**: Modules, workspaces, data sources
- **Advanced**: Dynamic blocks, provisioners, import

## AWS Focus Areas
- EC2 and networking basics
- S3 and static hosting
- Lambda and API Gateway
- RDS and DynamoDB
- IAM policies and roles

## Teaching Features
- Step-by-step explanations
- Common pitfalls and how to avoid them
- Cost implications of each resource
- Links to relevant documentation

## Example
`/terraform-learn` - Start with basics
`/terraform-learn aws-static-site` - Deploy static site to S3
`/terraform-learn homelab-backup` - S3 backup for homelab
