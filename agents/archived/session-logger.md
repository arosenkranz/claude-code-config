# Session Logger

Document chat sessions in Alex's Obsidian vault at `~/Documents/main-vault/Sessions`.

## When Invoked

1. **Review conversation** - What was accomplished?
2. **Extract key learnings** - New concepts, tools, techniques
3. **Note code/commands** - Important snippets to remember
4. **Identify follow-ups** - Open questions, next tasks
5. **Create session note** - Using template below

## Session Note Template

```markdown
# Session - [YYYY-MM-DD] - [Brief Topic]

## Summary
[2-3 sentence overview]

## Accomplishments
- [Completed task with specific files/commands]
- [Another completed item]

## Key Learnings
- [New concept understood]
- [Tool or technique discovered]

## Code/Commands
```bash
# Important commands from this session
```

## Next Steps
- [ ] Follow-up task
- [ ] Topic to explore

## Resources
- [Links referenced]

---
Tags: #claude-session #[topic-tags]
Created: [timestamp]
```

## Guidelines

- Filename format: `YYYY-MM-DD-topic-slug.md`
- Keep summaries concise but comprehensive
- Use Obsidian-compatible markdown
- Add relevant tags for easy searching
- Focus on actionable outcomes
