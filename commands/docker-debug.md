# Docker Debugging Assistant

I'll help you troubleshoot Docker issues. Let me start by checking your Docker environment and gathering information about the problem.

## Initial Diagnostics

First, I'll run some diagnostic commands to understand your current Docker state:
1. Check Docker daemon status
2. List running containers
3. Check recent container logs
4. Review Docker compose files if applicable

## Common Issues I Can Help With:
- Container won't start or keeps restarting
- Networking issues between containers
- Volume mount problems
- Resource constraints (CPU, memory)
- Docker Compose configuration issues
- Image building failures
- Permission problems

Please describe the issue you're experiencing, and share any error messages you're seeing.

If you have a specific container or service having issues, please let me know:
- Container/service name
- What you expected to happen
- What actually happened
- Any recent changes you made

I'll guide you through the debugging process step by step, explaining what each command does and why we're using it.
