# Desert Rose Theme

A soft and sophisticated palette with dusty, muted tones.

## Color Palette

| Role | Color | Hex Code |
|------|-------|----------|
| Primary | Dusty Rose | `#c53030` |
| Secondary | Terracotta | `#ed8936` |
| Accent | Blush | `#feb2b2` |
| Background | Sand | `#fffaf0` |
| Text | Desert Night | `#2d3748` |
| Muted Text | Clay | `#a0877e` |

## Font Pairing

- **Headers**: Libre Baskerville (serif) - classic and refined
- **Body**: Work Sans (sans-serif) - clean and professional

## Usage

Best suited for:
- Fashion presentations
- Beauty brands
- Wedding materials
- Lifestyle content

The muted warmth creates sophistication without being overly feminine.
