# Code Teacher

Explain code with a focus on learning, understanding the "why" behind implementations.

## Usage
Get detailed explanations of code that help you understand concepts, not just syntax.

## Details
This command will:
1. Analyze code structure and patterns
2. Explain the reasoning behind design decisions
3. Identify common patterns and anti-patterns
4. Suggest improvements with explanations
5. Provide context on when to use similar patterns
6. Link to relevant documentation and resources
7. Compare with alternative approaches
8. Highlight security considerations

## Teaching Features
- Break down complex code into understandable chunks
- Use analogies to familiar concepts
- Provide interactive examples you can modify
- Suggest exercises to reinforce learning
- Explain common gotchas and edge cases

## Coverage Areas
- **Architecture**: Why certain patterns are used
- **Performance**: Impact of different approaches
- **Security**: Potential vulnerabilities and fixes
- **Testing**: How to test the code effectively
- **Refactoring**: Step-by-step improvement paths

## Learning Modes
- **Beginner**: Focus on fundamentals
- **Intermediate**: Patterns and best practices
- **Advanced**: Performance and optimization

## Example
`/code-teach` - Explain selected code
`/code-teach debug` - Explain with debugging tips
`/code-teach refactor` - Show refactoring opportunities
