# Start Learning Session

I'll help you learn a new technology or concept through hands-on practice!

## What would you like to learn about?

Please tell me:
1. **Topic**: What technology, language, or concept interests you?
   - Examples: Go basics, Terraform, Kubernetes, AWS services, Linux administration, etc.

2. **Current Level**: What's your experience with this topic?
   - Complete beginner
   - Some familiarity
   - Looking to go deeper

3. **Learning Goal**: What would you like to achieve?
   - Understand the basics
   - Build something specific
   - Solve a particular problem
   - Prepare for a project

4. **Time Available**: How much time do you have for this session?
   - Quick 15-30 minute intro
   - 1-2 hour deep dive
   - Multi-session project

I'll then:
- Create a tailored learning plan
- Start with practical examples you can run
- Explain concepts as we build
- Suggest mini-projects to reinforce learning
- Connect new concepts to your existing knowledge
- Provide resources for continued learning

Remember: we learn by doing! I'll make sure you're writing and running code, not just reading about it.
